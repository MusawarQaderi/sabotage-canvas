# SABOTAGE CANVAS

Multiplayer‑Partyspiel: Zeichne, täusche und entlarve den Imposter.  
Node.js + Express + Socket.IO‑Server, statisches Frontend in public/.

## Live Demo
Die aktuelle, gehostete Demo ist verfügbar unter:

https://sabotage-canvas.onrender.com/

Über diesen Link kannst du das Spiel direkt im Browser ausprobieren (mehrere Fenster/Clients für Multiplayer verwenden).

## Features
- Mehrere Spieler in einem Raum (4‑stelliger Code)
- Ein "Imposter" kennt das geheime Wort nicht
- Abwechselnde Zeichen‑Turns mit Kurzzeit‑Timer (3s pro Zug)
- Voting‑ und Showdown‑Phasen
- Punktesystem für Imposter / Artists

## Voraussetzungen
- Node.js (>= 16) und npm
